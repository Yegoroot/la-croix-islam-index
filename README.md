# Образ ислама в газете «La Croix» — указатель статей

Рабочий указатель статей газеты *La Croix* об исламе для исследования
**«صورة الإسلام في صحيفة La Croix» (صحيفة الصليب)**, сгруппированный по оглавлению диссертации — **5 глав, 21 тема**.

## Файлы
- **`La-Croix-islam-index.html`** — готовый деливерабл. Открывать в браузере (двойной клик).
  Колонка «Автор», клик по автору/дате копирует значение, переключатель языка интерфейса **RU/FR**,
  раскрывающаяся **арабская аннотация** по каждой статье.
- **`lacroix_idx.json`** — 217 найденных статей (заголовок, ссылка, дата, рубрика) по темам.
- **`annotations.json`** — по каждой статье: автор + арабская аналитическая выжимка.
- **`build_html.py`** — пересобирает HTML из двух JSON. Запуск: `python3 build_html.py`.
- **`merge.py`** + `new_entries.json` — служебное добавление новых аннотаций.

## Как собрано
- Статьи найдены через Google (`site:la-croix.com` + ключевые слова по каждой теме) внутри
  залогиненного Chrome: собственный поиск La Croix закрыт CAPTCHA, а краулер Anthropic сайтом заблокирован.
- Арабские тексты — **аналитические выжимки** (о чём статья, тезисы, угол подачи La Croix), **не** дословный
  перевод и **не** копия статьи: полный текст нигде не хранится.
- Даты — из URL статьи, иначе из сниппета; «—» = не определено автоматически.

## Статус
**Готово: все 194 статьи аннотированы** (автор + арабская аналитическая выжимка) — `annotations.json`
содержит 194 записи. Служебные страницы (теги/досье/страны/«EN DIRECT») помечены как «للإحالة»
(справочные, не отдельная статья). Для статей, где ислам лишь фоновый сюжет (напр. политика Боснии),
в аннотации стоит пометка **«ملاحظة: البعد الإسلامي هامشيّ»**.

Пересобрать указатель после правок: `python3 build_html.py` (→ `La-Croix-islam-index.html`).
